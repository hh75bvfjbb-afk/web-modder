# Web Modder: инструкция по шагам

Web Modder — программа для Windows: открывается в браузере, вы пишете, какой мод нужен, и ИИ-агент
делает его с помощью universal-modder на вашем компьютере. Всё нужное лежит в одном файле
**`WebModder.exe`**: Python, универсальный моддер (universal-modder) и библиотеки для картинок.

---

## Часть 1. Скачать и запустить Web Modder

1. Откройте страницу сборки:
   **https://github.com/hh75bvfjbb-afk/web-modder/releases/tag/webmodder-latest**
   (нужно войти в GitHub под своим аккаунтом, если репозиторий приватный).
2. В разделе **Assets** скачайте **`WebModder.exe`** (~80 МБ).
   Если релиза нет, его можно взять во вкладке **Actions** → последний запуск **build-exe** →
   внизу **Artifacts** → `WebModder-windows` (zip, внутри exe).
3. Положите `WebModder.exe` в любую папку, например `C:\WebModder\`.
4. Запустите двойным щелчком.
   - Windows может показать синее окно **«Windows защитила ваш компьютер»**: файл не подписан
     сертификатом. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
   - Если антивирус ругается — добавьте файл в исключения (это частая реакция на exe, собранные PyInstaller).
5. Откроется чёрное окно консоли и браузер со страницей Web Modder.
   - **Не закрывайте чёрное окно**, пока работаете: это и есть сервер. Закрыли — Web Modder выключился
     (незаконченные задачи продолжатся при следующем запуске).
   - Если браузер не открылся, скопируйте из консоли ссылку вида `http://127.0.0.1:8765/?token=…`.
     Токен также лежит в `%USERPROFILE%\.web-modder\token.txt`.

При первом запуске Web Modder распаковывает universal-modder в `%USERPROFILE%\.web-modder\`.

## Часть 2. Ключи (без них агент ждёт)

Нужен хотя бы один ключ к ИИ-модели. Самый дешёвый путь — **FreeLLMAPI**: он собирает бесплатные лимиты
десятков сервисов в один ключ. Можно и просто вставить обычный ключ (Claude, OpenAI, Gemini…) — шаг 2.6.

### 2.1. Установить FreeLLMAPI
1. Откройте **https://github.com/tashfeenahmed/freellmapi/releases/latest**.
2. Скачайте установщик для Windows (`.exe` со словом *Setup*/*win* в названии) и установите.
3. Запустите FreeLLMAPI — появится значок в трее (возле часов). Сервер работает на `http://localhost:31415`.

### 2.2. Получить бесплатные ключи провайдеров
Зарегистрируйтесь и создайте ключи (бесплатно, карта не нужна) — чем больше, тем дольше хватит лимитов:

| Сервис | Где взять ключ |
|---|---|
| Google Gemini | https://aistudio.google.com/apikey |
| Groq | https://console.groq.com/keys |
| Cerebras | https://cloud.cerebras.ai |
| OpenRouter | https://openrouter.ai/keys |
| Mistral | https://console.mistral.ai/api-keys/ |
| NVIDIA NIM | https://build.nvidia.com/settings/api-keys |

### 2.3. Добавить их в FreeLLMAPI
1. Щёлкните значок FreeLLMAPI в трее → **Open FreeLLMAPI**.
2. Страница **Keys** → добавьте каждый ключ к своему провайдеру.
3. На той же странице (вверху) или во всплывающем окне трея скопируйте **единый ключ** `freellmapi-…`.

### 2.4. Подключить FreeLLMAPI к Web Modder
1. В Web Modder нажмите вверху **«ключи: 0/0»** (вкладка «Ключи»).
2. Блок **«Роутер FreeLLMAPI»** должен показать **«найден: http://localhost:31415»**.
   (Если у вас Docker-версия FreeLLMAPI — впишите адрес `http://localhost:3001`.)
3. Вставьте единый ключ `freellmapi-…`.
4. **Выбор моделей**: оставьте `auto:smart` (самые умные бесплатные модели).
5. **Лимит токенов в месяц** — по желанию, например `50000000`. Когда лимит кончится, ключ сам встанет на
   паузу и **сам пополнится 1-го числа**. Пусто = без лимита.
6. **«Подключить FreeLLMAPI»**. Кнопка **«Состояние роутера»** покажет, какие провайдеры работают и
   сколько осталось бесплатных лимитов.

### 2.5. Ключ fal.ai для картинок, 3D и звука (по желанию)
Спрайты, модели и звуки агент делает через fal.ai: ключ на https://fal.ai/dashboard/keys
(вид `xxxxxxxx-xxxx-…:xxxx`). Вставьте его в поле «Ключи» на той же вкладке → «Добавить / пополнить».
Без него агент сделает заглушки или предложит другие варианты.

### 2.6. Обычные ключи (по желанию, как запасной вариант)
Любой ключ — `sk-ant-…` (Claude), `sk-…` (OpenAI), `sk-or-…` (OpenRouter), `AIza…` (Gemini) и др. —
вставьте в поле «Ключи» → «Добавить / пополнить». Провайдер определится сам. Порядок использования
меняется стрелками ↑↓. Когда бесплатные лимиты FreeLLMAPI закончатся, агент сам перейдёт на следующий ключ.

## Часть 2½. Установите Git (важно)

Скачайте и установите **Git for Windows**: https://git-scm.com/download/win (все настройки по умолчанию).
Вместе с ним ставится **Git Bash**, и Web Modder выполняет команды агента через него: ИИ-модели почти всегда
пишут команды для bash (`ls`, `cat`, `&&`, `<< EOF`), а в PowerShell такие команды падают с ошибками.
Внизу слева в Web Modder должно быть написано **«Git Bash (bash on Windows)»**, а не «Windows PowerShell 5.1».
После установки Git перезапустите `WebModder.exe`.

## Часть 3. Сделать мод

1. **«＋ Новый мод»**.
2. **Игра**: название (список установленных Steam/Epic/Xbox-игр подсказывается) или путь к папке игры.
3. **Идея**: опишите, что нужно, например
   *«Добавь ракетницу с самонаводящимися ракетами и ядерную бомбу, которая оставляет кратер. Спрайты — через fal.»*
4. **«Начать»**. Дальше агент работает сам, а вы видите каждый шаг:
   - ищет опыт других в базе знаний, определяет движок игры, выбирает способ моддинга;
   - **делает бэкап сохранений**, пишет код мода, генерирует ассеты, проверяет в игре;
   - **задаёт вопросы** — отвечайте кнопками или текстом;
   - **просит подтверждение** на рискованное (запуск игры, управление мышью/клавиатурой, установка в папку
     игры, реестр) — «Разрешить» / «Разрешать всегда» / «Запретить».
5. Писать агенту можно в любой момент в поле внизу. **«Стоп»** — остановить, **«Продолжить»** — продолжить.
6. **«Файлы»** — папка мода. Все моды лежат в `%USERPROFILE%\WebModder\`, у каждого есть журнал `MODLOG.md`.

Ограничения (правила universal-modder): только ваши игры, одиночная игра / офлайн / ваш сервер; никаких читов
для онлайна и обхода античита/DRM.

## Часть 4. Что ещё может понадобиться (агент скажет сам)

| Программа | Зачем |
|---|---|
| Git — https://git-scm.com/download/win | **нужен**: команды агента через Git Bash, обновление universal-modder |
| ffmpeg — `winget install ffmpeg` | запись и монтаж видео с модом |
| Blender — https://www.blender.org | 3D-модель → спрайты |
| .NET SDK, Java, загрузчик модов (tModLoader, BepInEx, Fabric…) | зависит от игры |

## Частые проблемы

| Проблема | Что делать |
|---|---|
| Статус **«ждёт ключ»** | Все ключи на паузе или их нет. Добавьте ключ или подождите — агент продолжит сам |
| FreeLLMAPI «не запущен» | Запустите FreeLLMAPI (значок в трее) и обновите страницу |
| Агент пишет `ls -la`, `cat << EOF` и получает ошибки | Не установлен Git: см. «Часть 2½». Внизу слева должно быть «Git Bash» |
| Вместо русского текста в ошибках `��ы�` | Обновите `WebModder.exe` — исправлено |
| `⚠ FreeLLMAPI … сервер перегружен — HTTP 502 … Provider error` | Один бесплатный провайдер сбоит; Web Modder ждёт несколько секунд и повторяет — роутер выберет другого. Если повторяется часто, отключите этого провайдера/модель в панели FreeLLMAPI |
| Агент путается, код не компилируется (`error CS0246`, «не удалось разрешить ссылку») | Слабая бесплатная модель (например Nemotron). В панели FreeLLMAPI отключите слабые модели или закрепите сильную (Gemini 2.5 Pro и т. п.); в Web Modder у ключа FreeLLMAPI выберите `auto:smart` или конкретную модель из списка; для сложных модов добавьте платный ключ (Claude) вторым — он подхватит работу |
| Задача зашла в тупик | Нажмите «Стоп», напишите агенту, что не так, например: «используй шаблон tModLoader и проверь using для TagCompound», затем «Продолжить» |
| Порт 8765 занят | Запустите из консоли: `WebModder.exe --port 8800` |
| Нужно открыть с другого устройства в сети | `WebModder.exe --host 0.0.0.0` (любой с токеном сможет управлять ПК — осторожно) |
| Обновить universal-modder | Слева внизу «обновить» |
| Обновить сам Web Modder | Скачайте новый `WebModder.exe` и замените старый — ключи и моды сохранятся |

Где что хранится: ключи и сессии — `%USERPROFILE%\.web-modder\`, моды — `%USERPROFILE%\WebModder\`.

## Для разработчика: запуск из исходников и сборка exe

```bat
:: запуск без сборки (нужен Python 3.10+)
start.bat

:: собрать WebModder.exe самому (на Windows)
python -m pip install -r requirements.txt pyinstaller
python packaging\build_exe.py
:: результат: dist\WebModder.exe
```

Каждый push в репозиторий автоматически собирает и проверяет exe на Windows
(`.github/workflows/build-exe.yml`) и обновляет релиз `webmodder-latest`.
