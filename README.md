# Web Modder

Веб-интерфейс, который **по запросу модифицирует любые PC-игры**: вы пишете в браузере «добавь в Terraria
ракетницу с самонаводящимися ракетами», а ИИ-агент делает весь мод — от разведки движка до проверки
в настоящей игре. Под капотом работает [universal-modder](https://github.com/rehan-remade/universal-modder):
его навыки (skills), CLI `um`, общая база знаний и правила безопасности.

```
браузер ──► локальный сервер Web Modder ──► ИИ-агент (любой ваш ключ) ──► инструменты universal-modder
             (127.0.0.1, токен)              Claude / GPT / Gemini / …      um scan · um kb · um fal ·
                                             с автопереключением ключей     um sprite · um win · um backup …
                                                                            ──► игра на этом ПК
```

## Почему это локальное приложение, а не сайт в интернете

Моды делаются с **установленной у вас игрой**: агент читает её файлы, ставит загрузчики, делает бэкап
сохранений, запускает игру и снимает скриншоты. Удалённый сайт этого не может, поэтому Web Modder запускается
на том же ПК, где стоят игры (Windows, или WSL/Linux/macOS), и открывается в обычном браузере.
Сервер слушает только `127.0.0.1` и пускает лишь по секретному токену.

## Запуск

Нужны Python 3.10+ и Git (для `um` также пригодятся ffmpeg, а для 3D → спрайты — Blender).

```bash
git clone <этот репозиторий> && cd web-modder
start.bat          # Windows
./start.sh         # Linux / macOS / WSL
# или вручную:
pip install -r requirements.txt && python run.py
```

При первом запуске приложение само скачает universal-modder в `~/.web-modder/universal-modder`
и откроет браузер по ссылке вида `http://127.0.0.1:8765/?token=…`.

Параметры: `--port 8765`, `--no-browser`, `--add-key КЛЮЧ` (можно несколько раз), `--host` (по умолчанию
только этот ПК). Переменные: `WM_HOME` (данные), `WM_MODS` (папка модов, по умолчанию `~/WebModder`),
`WM_TOOLKIT` (свой клон universal-modder), `WM_TOKEN` (свой токен).

## Ключи: пополнение с любого ключа и работа без перерывов

Вкладка **«Ключи»** принимает **любой** ключ — провайдер определяется по виду ключа, а неоднозначные
(`sk-…`, ключи без префикса) проверяются запросом к API:

| Ключ | Провайдер |
|---|---|
| `sk-ant-…` | Anthropic (Claude) — по умолчанию `claude-opus-5-5` |
| `sk-or-…` | OpenRouter (любые модели) |
| `sk-proj-…`, `sk-…` | OpenAI или DeepSeek |
| `AIza…` | Google Gemini |
| `gsk_…`, `xai-…`, `fw_…` | Groq, xAI, Fireworks |
| без префикса | Mistral, Together |
| `freellmapi-…` | FreeLLMAPI — роутер бесплатных ключей (см. ниже) |
| `uuid:secret` | fal.ai — для генерации спрайтов, 3D, звука (`um fal`) |
| адрес сервера | любой OpenAI-совместимый: Ollama, LM Studio, vLLM… |

### FreeLLMAPI: один ключ на все бесплатные лимиты

Рекомендуемый способ. [FreeLLMAPI](https://github.com/tashfeenahmed/freellmapi) — локальный роутер, который
собирает бесплатные лимиты 30+ провайдеров (Gemini, Groq, Cerebras, Mistral, OpenRouter, NVIDIA, Cloudflare…)
за одним OpenAI-совместимым адресом и сам переключается между ними при лимитах.

1. Установите FreeLLMAPI: [установщик для Windows/macOS](https://github.com/tashfeenahmed/freellmapi/releases/latest)
   или `curl -fsSL https://freellmapi.co/install.sh | bash` (Docker).
2. Откройте его панель `http://localhost:3001`, добавьте ключи провайдеров на странице **Keys**
   и скопируйте оттуда единый ключ `freellmapi-…`.
3. В Web Modder на вкладке «Ключи» заполните блок **«Роутер FreeLLMAPI»**: адрес, единый ключ, стратегию
   (`auto:smart` — самые умные модели, по умолчанию; `auto`, `auto:reliable`, `auto:balanced`, `auto:fast`)
   и, по желанию, **лимит токенов в месяц**.

Роутер встаёт первым в очереди. Web Modder помечает запросы как кодинг (`X-FreeLLM-Task-Type: code`),
показывает в ленте, какая модель реально ответила (`X-Routed-Via`), а кнопка «Состояние роутера» выводит
здоровье провайдеров и остатки квот (`/v1/providers`, `/v1/quota-forecast`). Если у FreeLLMAPI закончился
месячный лимит (`429 quota_exceeded`), ключ встаёт на паузу ровно до сброса, который назвал роутер, а работа
продолжается на других ваших ключах, если они есть.

### Месячный лимит, который пополняется сам

У каждого ключа (и у FreeLLMAPI) можно задать **лимит токенов в месяц**. Web Modder считает токены за текущий
месяц; когда лимит израсходован, ключ встаёт на паузу до 00:00 UTC 1-го числа следующего месяца (так же
сбрасывает свои лимиты FreeLLMAPI), а потом счётчик обнуляется и ключ **сам возвращается в работу**. Чтобы
пополнить раньше, поднимите лимит — ключ включится сразу. Общий расход за всё время тоже сохраняется.

Как агент «не прерывается»:

- Ключи используются по приоритету (стрелки ↑↓). Сессия держится за текущий ключ, пока он работает.
- **Лимит запросов / перегрузка / сеть** → ключ уходит на паузу (с учётом `Retry-After`), агент сразу
  продолжает на следующем ключе, даже у другого провайдера — история переносится без потерь.
- **Кончились деньги или квота** → ключ на паузе 30 минут и потом пробуется снова сам: пополните счёт у
  провайдера, и агент подхватит ключ без перезапуска.
- **Ключ отозван / модель недоступна** → ключ отключается до «Проверить и включить».
- **Нет ни одного рабочего ключа** → сессия не падает, а ждёт («ждёт ключ») и продолжает с того же места,
  как только вы вставите новый ключ.
- **Пополнить** = вставить тот же ключ ещё раз (он перепроверяется и включается) или поднять его
  месячный лимит; иначе ключ пополнится сам 1-го числа.
- Сессии сохраняются после каждого шага: после перезапуска сервера или ПК незавершённые задачи
  продолжаются автоматически.
- Если модель упирается в размер контекста, старые шаги сжимаются, а агент восстанавливает ход работы из
  журнала `MODLOG.md`.

Ключи хранятся только у вас (`~/.web-modder/keys.json`, права 600), в браузер уходят маскированными
и не передаются в команды, которые выполняет агент (кроме `FAL_KEY` для `um fal`).

## Что делает агент

Агент получает инструкции universal-modder (`AGENTS.md`, навык `mod-any-game`, список всех навыков)
и проходит его цикл: база знаний (`um kb search`) → разведка (`um scan`) → выбор пути → бэкап сохранений
(`um backup`) → чтение кода игры → первый рабочий кусок → ассеты (`um fal`, `um sprite`, `um render3d`) →
проверка в игре (`um win launch/shot`) → видео (`um video`) → упаковка (`um publish check`) → заметка в
базу знаний.

Инструменты агента: `shell`, `um`, чтение/запись/правка файлов, `read_skill` (навыки и движковые плейбуки),
`view_image` (смотрит на скриншоты и спрайты), `fetch_url` (вики, GitHub, Nexus), `ask_user`.

В интерфейсе видно каждое действие в реальном времени, есть панель файлов сессии, можно писать агенту
по ходу работы, остановить и продолжить.

### Подтверждения

- **Умные** (по умолчанию) — без вопросов выполняются чтение, `um scan/kb/fal/sprite/video/backup create`,
  запись внутри папки сессии; спрашивается то, что universal-modder требует подтверждать: запуск и
  управление игрой (`um win drive/launch/kill`), реестр, установка в папку игры, удаление, публикация,
  произвольные команды оболочки.
- **Спрашивать всё** и **Без подтверждений** — переключаются в шапке сессии.

### Правила (из universal-modder, агент их не нарушает)

Только игры, которыми вы владеете; одиночная игра, офлайн или ваши собственные серверы. Никакого
вмешательства в онлайн-клиенты с античитом, никаких читов против других игроков, никакого обхода
античита, DRM и проверок владения. Бэкап до первого модифицированного запуска. Игровые файлы и
декомпилированный код не публикуются.

## Устройство

```
run.py / start.*         запуск
webmodder/
  server.py              HTTP-сервер: страница, JSON API, поток событий (SSE), токен доступа
  agent.py               сессии и цикл агента: переживает перезапуски, ждёт ключи, сжимает контекст
  keys.py                пул ключей: определение провайдера, приоритеты, паузы, лимиты, пополнение
  providers.py           Anthropic (официальный SDK) и любой OpenAI-совместимый API в одном формате истории
  tools.py               инструменты агента и правила подтверждений
  toolkit.py             клон universal-modder, навыки, запуск `um`
  static/                интерфейс (без сборки, без внешних зависимостей)
tests/                   офлайн-тесты с поддельным провайдером
```

Тесты: `pip install pytest && WM_TEST_TOOLKIT=<клон universal-modder> python -m pytest -q tests`.
